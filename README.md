# Traffic Light Controller using Verilog

## Overview
Designed a Finite State Machine (FSM) based traffic light controller using Verilog HDL. The controller manages the transition between Red, Yellow, and Green signals based on predefined timing sequences.

## Features
- FSM-based traffic signal control
- Sequential state transitions
- Functional verification using a Verilog testbench
- RTL design for digital logic implementation

## Tools Used
- Verilog HDL
- Xilinx Vivado
